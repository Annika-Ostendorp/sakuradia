# SAKURADIA

### Windows
```txt
1. Doppelklick auf start-dev.bat
```

### Mac
```txt
1. Terminal (IN DIESEM ORDNER!) öffnen
2. `chmod +x start-dev.command` ausführen
3. Doppelklick auf `start-dev.command`
```

### Manuell starten
```txt
1. cd game
2. npm install
3. npm run dev
4. Öffne http://localhost:5173/ in deinem Browser
```
